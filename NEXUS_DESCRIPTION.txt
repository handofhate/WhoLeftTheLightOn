[center][b][size=6]Who Left The Light On?[/size][/b][/center]
[center][size=4]Persistent lighting and vehicle preferences for Moon Sweepers[/size][/center]

[center][b][size=5]Version 1.0.0[/size][/b][/center]
[center]Target game build: Moon Sweepers 1.0.6 preview[/center]

[b][size=4]WHAT IT DOES[/size][/b]

Who Left The Light On? remembers the settings you actually use and restores them when you need them again. It works with the game's existing systems and does not add custom light modes or modify save-game data.

[b][size=4]FEATURES[/size][/b]

[list]
[*]Remembers the player's last helmet lighting mode: Off, Flashlight, or Night Vision.[/*]
[*]Remembers vehicle lights separately for each vehicle.[/*]
[*]Restores saved vehicle lights when vehicles spawn, before you mount them.[/*]
[*]Remembers adjustable suction power separately for each vehicle.[/*]
[*]Provides per-vehicle Vehicle Boost Lock. Left Shift toggles persistent boost mode while driving; braking, stopping, and exiting do not clear it.[/*]
[*]Stores preferences locally in BepInEx/config/.[/*]
[*]Supports normal BepInEx loading and optional Lunar Link hot swapping and in-game updates.[/*]
[/list]

[b][size=4]SETTINGS[/size][/b]

The settings are available in Lunar Link's F9 window under the expanded Who Left The Light On? row, and in compatible mod-manager settings screens. The four functional settings default to On.

[list]
[*][b]Remember Helmet Lighting[/b] restores Off, Flashlight, or Night Vision.[/*]
[*][b]Remember Vehicle Lights[/b] remembers each vehicle's light state independently.[/*]
[*][b]Remember Vehicle Suction[/b] remembers each vehicle's adjustable suction setting independently.[/*]
[*][b]Vehicle Boost Lock[/b] makes Left Shift toggle persistent boost mode for the current vehicle.[/*]
[*][b]Clear Remembered Vehicle Settings[/b] is a one-shot reset. Set it to On and apply once; it clears stored vehicle lights, suction, and boost preferences, then returns to Off.[/*]
[/list]

The settings file is [font=Courier New]BepInEx/config/tylerun.moonsweepers.wholeftthelighton.cfg[/font]. The remembered runtime state is [font=Courier New]BepInEx/config/WhoLeftTheLightOn.preferences[/font].

[b][size=4]REQUIREMENTS[/size][/b]

[list]
[*]Moon Sweepers.[/*]
[*]BepInEx 6 IL2CPP for Moon Sweepers.[/*]
[*]The Moon Sweepers BepInEx compatibility patcher.[/*]
[*]MoonFramework, as required by the current Moon Sweepers mod setup.[/*]
[*]Lunar Link is optional, but required for hot loading and in-game updates.[/*]
[/list]

[b][size=4]NORMAL INSTALLATION[/size][/b]

[list=1]
[*]Close Moon Sweepers completely.[/*]
[*]Install and verify BepInEx and the Moon Sweepers compatibility patcher.[/*]
[*]Extract the archive into the Moon Sweepers installation directory.[/*]
[/list]

The normal plugin path is:

[font=Courier New]Moon Sweepers/BepInEx/plugins/WhoLeftTheLightOn/WhoLeftTheLightOn.dll[/font]

[b][size=4]LUNAR LINK INSTALLATION[/size][/b]

With Lunar Link installed, place the DLL directly at:

[font=Courier New]Moon Sweepers/BepInEx/hot/WhoLeftTheLightOn.dll[/font]

Do not leave another active copy in [font=Courier New]BepInEx/plugins[/font]. A normal copy and a hot copy can load twice. Use Lunar Link's F9 window to enable, reload, disable, or update the hot module.

Lunar Link can check the published GitHub releases and update the hot module in place without a game restart.

[b][size=4]UNINSTALLATION[/size][/b]

[list]
[*]Close Moon Sweepers.[/*]
[*]Remove the installed DLL from [font=Courier New]BepInEx/plugins/WhoLeftTheLightOn/[/font] or [font=Courier New]BepInEx/hot/[/font].[/*]
[*]Optionally remove [font=Courier New]BepInEx/config/WhoLeftTheLightOn.preferences[/font] and [font=Courier New]BepInEx/config/tylerun.moonsweepers.wholeftthelighton.cfg[/font] to remove stored preferences.[/*]
[/list]

[b][size=4]COMPATIBILITY NOTE[/size][/b]

The 1.0.0 release was built and checked against the Moon Sweepers 1.0.6 preview environment. Game updates can change internal vehicle or lighting behavior and may require a compatibility update.
