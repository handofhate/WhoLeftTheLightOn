# Who Left The Light On?

Remembers the player's last flashlight mode between game launches.

The game has three modes: off, flashlight, and night vision. The mod watches the vanilla light controls and restores the last stable mode when the player is ready.

## Installation

For a normal BepInEx installation, place the DLL at:

`BepInEx/plugins/WhoLeftTheLightOn/WhoLeftTheLightOn.dll`

With Lunar Link installed, the mod can be hot-swapped without restarting the game. Place it at:

`BepInEx/hot/WhoLeftTheLightOn.dll`

Do not leave another active copy in `BepInEx/plugins`. Use Lunar Link's F9 window to enable or reload the hot copy.

Lunar Link can also report published GitHub releases in its Updates window.
